# RetailMax Sales Analytics
## Documento de Requisitos

### 1. Contexto

A RetailMax é uma empresa do setor varejista que possui operações
em diferentes regiões.

Atualmente, os dados de vendas encontram-se distribuídos em
diferentes fontes, dificultando a análise do desempenho comercial.

### 2. Problema

A equipa de gestão possui dificuldade para responder rapidamente:

- Quais regiões apresentam melhor desempenho?
- Quais produtos geram maior receita?
- Quais produtos geram maior lucro?
- Quais clientes possuem maior valor de compra?
- Como as vendas evoluem ao longo do tempo?

### 3. Objetivo

Desenvolver uma solução de análise de dados capaz de consolidar
informações de vendas e gerar indicadores para apoiar a tomada
de decisão.

### 4. Stakeholders

- Diretoria
- Gerência comercial
- Gerentes regionais
- Equipe de vendas
- Equipe de dados

### 5. Entregáveis

- Base de dados estruturada
- Análises exploratórias
- Consultas SQL
- Dashboard executivo
- Documentação técnica

### 6. Indicadores

- Receita
- Lucro
- Quantidade de vendas
- Ticket médio
- Margem de lucro
- Crescimento das vendas

### 7. Critérios de sucesso

A solução deverá permitir que a gestão responda às principais
questões de negócio relacionadas ao desempenho das vendas.
