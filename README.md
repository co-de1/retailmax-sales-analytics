# RetailMax Sales Intelligence

Sistema de análise de vendas desenvolvido pela Insight Analytics para fornecer *indicadores estratégicos de desempenho*, dashboards executivos e análises exploratórias para tomada de decisão.

## Objetivos

- Consolidar dados de vendas
- Analisar KPIs de negócio
- Construir dashboards executivos
- Disponibilizar dados para futuras soluções de Machine Learning
